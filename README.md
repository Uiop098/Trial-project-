## 🌟 Overview

This repository is an experimental trial project exploring modern front-end design techniques:
- Cyberpunk form inputs with animated focus glow.
- Real-time Light & Dark theme toggle.
- Interactive background particle canvas.
- Client-side form validation and profile customizer.
